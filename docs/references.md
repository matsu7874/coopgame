# 参考文献と、主張の根拠

このリポジトリのコード・テスト・ドキュメントが依拠する文献の一覧である。
どの主張をどの文献から取り、リポジトリのどこで使い、計算でどう確かめているかを対応づける。

## 確認した範囲 (2026-11-23 時点)

- 書誌情報 (著者・題名・誌名・巻・ページ・DOI) は、出版社のページ、RePEc/IDEAS、図書館目録、
  arXiv のいずれかで確認した。確認に使った情報源を「確認元」に示す。
- 主張の内容は、次のどれで確認したかを「確認元」と「主張と根拠」の表に書く。
  - 原典の本文 (公開されている版を含む): 確認元に「本文」と書き、節・式・定理の番号を記載する。
    公開版 (研究所の報告書など) で確認したものは、誌の版と番号や頁が異なりうるので、読んだ版を書く。
  - 原典の定義・定理を式で引用している文献の本文: 「引用文献」と書き、その文献と節・式・定理の番号を記載する。
    原典の本文で確かめたことにはならないので、原典の該当箇所は未確認として扱う。
  - 原典の要旨や題名、検索結果の要約だけ: そう書く。
- 2026-11 に、次の原典を公開版の本文で確認した: DM1965 (Princeton 大学 Econometric Research Program の
  Research Memorandum No. 58、1963)、MPS1979 (RAND P-6027、1977)、MPS1971 (Hebrew University の Research Memorandum No. 25、1967)。
  交渉集合は AM1964 の前身 (RM 34) と DM1962 (RM 38)、Banzhaf 値の正規化は DS1979 (RAND P-6016)、Coleman の指数は RAND P-3902 の本文で確認した。
  Koh1971、AD1974、Owe1977、Bir1976、Owe1975、Ban1965、Joh1978、DP1978 (誌の版)、Hol1982、NR1994、Grotte (1970) は公開版が見つからず、引用文献の本文で確認した。
  PS2007 と Maschler–Solan–Zamir の教科書は、公開版も利用者の蔵書の全文検索でも見つからず、本文を確認していない。
- 仁の変種について、次の文献の本文は未確認である: Sudhölter (1996, *Mathematics of Operations Research* 21(3))、
  Sud1997、PS2007 (modiclus の章)、LV1976、Grotte (1970)。
- 文献の主張のうち計算で確かめられるものは、テストかデータで確かめている (「計算での確認」の列)。

## 定義の選び方と、保証の範囲

文献によって定義に変種があるもの、解が一意でないもの、保証の対象を限っているものについて、実装の選び方を書く。

| 対象 | 実装の選び方 | 根拠 |
|---|---|---|
| 交渉集合 (`bargaining`) | 提携構造は全体提携だけの `M_1^(i)`。異議 `(y, S)` は `y(S) = v(S)` で、`S` の全員が狭義に増える (`y_k > x_k`)。反論 `(z, T)` は `z(T) = v(T)` で、`k ∈ T` のうち `S` に属さない人は `z_k >= x_k`、`S` に属する人は `z_k >= y_k` (弱い不等式)。`y`・`z` に個人合理性を明示では課さない。交渉集合では `x` を配分、プレ交渉集合では準配分にする | DM1962 の定義 2.1 は、異議を出す人だけ狭義で他は弱い不等式とし、脚注で全て狭義にしても一般性を失わないと書く。RM 34 (AM1964 の前身) の定義 2.1 も異議の側の全員を狭義にする。DM1962 も `y`・`z` に個人合理性を課していない。`x` が配分なら、`S` のメンバーは `y_k > x_k >= v({k})`、`T` のメンバーは `z_k >= x_k` か `z_k >= y_k` なので、提携のメンバーについては個人合理性が自動的に成り立つ。RM 34 が主に扱う集合 `M` は、異議・反論の支払いにも提携合理性を課す別の定義である |
| Banzhaf 値 (`values::banzhaf`) | 決定票の数 (限界貢献の和) を `2^(n-1)` で割る (正規化しない)。和を 1 にした値は `values::normalize`、CLI の `--normalize` | DS1979 の式 (2) (swing probability)。和で割る値は同じ文献の式 (1)。Ban1965 自身は決定票の数とその比を使った (FM2004 の 4 節) |
| Bird 規則 (`SpanningTreeGame::bird_rule`) | 供給元から Prim 法で最小全域木を 1 つ作り、各プレイヤーは自分を木につないだ辺 (親への辺) の費用を払う。最小全域木が複数あるときは、次に加える頂点を、つなぐ費用が最小のもののうち番号の小さい方とし、各頂点をつなぐ辺は、費用が同じなら先に木に入った頂点 (最初は供給元) からの辺を残す。このため、選ばれる木と分担は入力の番号付けで決まる。複数の木の分担を平均する規則は実装していない | Bird は特定の最小全域木について規則を定義した (DM2011 の脚注 9)。どの最小全域木についても、その分担はコアに属する (BV2020 の Theorem 3.1(1) が Bir1976 として引用)。`bird_rule_and_nucleolus_lie_in_core` で確かめている |
| Owen 配分 (`LinearProductionGame::owen_allocation`) | 全員の LP の双対問題を microlp で解き、返った最適解 1 つを影の価格として使う。双対問題の最適解が一意でないときは、どの最適解が返るかは microlp の手順で決まり、配分もそれに応じて変わる | 双対問題のどの最適解から作った配分もコアに属する (PPF2012 の式 (7) が Owe1975 として引用)。Owen 配分の集合全体は返さない |
| 破産ゲームの凸性 (`BankruptcyGame` の `Proven`) | `Proven(convex)` は、入力の請求額と遺産を実数とみなした数学的なゲーム `v(S) = max(0, (E - D) + d(S))` が凸であることの保証である (Lean で証明。[proofs/README.md](../proofs/README.md))。`SetFunction::value` が返す `f64` の値そのものは、和の丸めにより、優モジュラ性の不等式を丸め誤差の大きさでわずかに破ることがある (請求額が小数のときなど) | 凸性を使う手法 (凸ゲームの手法、カーネル = 仁) は許容誤差の範囲で解く。破産ゲームの仁は閉じた形 (タルムード則) で求め、凸性を使わない |

この表にない主張 (制約生成の正しさ、Kohlberg 判定の打ち切り条件、カーネル全体の探索の正しさ、
オラクル版で確定させる提携を LP の行から選んでよいことなど) は、
リポジトリ内で導いたものである。導出はそれぞれのモジュールのドキュメントコメントに書き、テストで確かめている。
このうち、破産ゲーム・誘導部分グラフゲーム・空港ゲームの節約ゲームの凸性、劣モジュラ最小化の双対ギャップの下界、
Kohlberg 判定の打ち切り条件と平衡性の LP への書き換えは、Lean 4 で証明している ([proofs/README.md](../proofs/README.md))。
