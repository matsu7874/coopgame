# 文献の例の再現

教科書・論文・既存パッケージで答えが示されている例を、このライブラリで再現した。
テストは `tests/literature.rs` にある (`cargo test --release --test literature`)。

## 結論

- 文献の 3 人ゲーム 3 例と 4 人ゲーム 1 例で、仁・プレ仁が文献の値と一致した。
  CoopGame と TUGLab も同じ値を返した。
- タルムードの 3 事例と、ランダムな破産問題 300 個で、仁が Aumann–Maschler (1985) のタルムード則と一致した。
- Shapley 値・Banzhaf 値は、Ibn Ezra の相続問題、空港ゲーム、手袋ゲームなど文献の例で一致した。

## 手計算

### Peleg–Sudhölter Example 5.5.12

v(12) = 10、v(N) = 2、他は 0。プレ仁は対称性から x1 = x2 = a、x3 = 2 - 2a とおける。
超過は e(12) = 10 - 2a、e(3) = 2a - 2、e(13) = e(23) = a - 2、e(1) = e(2) = -a。
最大の超過は e(12) と e(3) の大きい方で、両者が等しい a = 3 で最小になる (値は 4)。
このとき e(13) = 1、e(1) = -3 は 4 より小さいので、プレ仁は (3, 3, -4) である。

仁は x3 >= 0 を課す。e(12) = 8 + x3 は x3 = 0 で最小になり、
残りの x1 + x2 = 2 では e(1) = e(13) = -x1 と e(2) = e(23) = -x2 を釣り合わせて (1, 1, 0) になる。

### Ferguson の 3 人ゲーム

v(1) = -1、v(2) = 0、v(3) = 1、v(12) = 3、v(13) = 4、v(23) = 2、v(N) = 5。
2 人提携の超過は e(12) = x3 - 2、e(13) = x2 - 1、e(23) = x1 - 3 で、その和は 5 - 6 = -1 と配分によらない。
3 つの最大値は 3 つを全て -1/3 にしたときに最小になり、その点は (8/3, 2/3, 5/3) の 1 つだけである。
1 人提携の超過 (-11/3, -2/3, -2/3) は -1/3 より小さい。配分集合 (x1 >= -1, x2 >= 0, x3 >= 1) にも入るので、
仁とプレ仁は一致する。

### CoopGame テスト 67.1

v(1) = 2、v(2) = 6、v(3) = 5、v(12) = 15、v(13) = 1、v(23) = 18、v(N) = 14。
2 人提携の超過は e(12) = x3 + 1、e(23) = x1 + 4、e(13) = x2 - 13。

- 仁: 配分集合 (x1 >= 2, x2 >= 6, x3 >= 5) で、最大の超過は max(x1 + 4, x3 + 1) >= 6。
  x1 = 2、x3 = 5 で両方が 6 になり、x2 = 7。仁は (2, 7, 5)。
- プレ仁: e(1) + e(23) = 6 と e(3) + e(12) = 6 は配分によらないので、最大の超過は 3 以上。
  e(1) = e(23) = 3 から x1 = -1、e(3) = e(12) = 3 から x3 = 2、x2 = 13。
  このとき e(2) = -7、e(13) = 0 で 3 より小さい。プレ仁は (-1, 13, 2)。

## Shapley 値・Banzhaf 値

| 例 | 出典 | 答え | 答えの裏付け |
|---|---|---|---|
| Ibn Ezra の相続問題 (遺産 120、請求 120, 60, 40, 30) | Aum2010 (CoopGame の `shapleyValue` のヘルプが引用) | Shapley 値 (80 5/6, 20 5/6, 10 5/6, 7 1/2) | 引用元の記載、LO1973 の公式による手計算 |
| ランダムな空港ゲーム 100 個 (n = 2-10) | LO1973 | 費用の増分を必要とする人数で等分した和 | 論文の公式を独立に実装 |
| Gambarelli の例 (辞書式順で 0, 0, 0, 1, 2, 1, 3) | Gambarelli (2011) (CoopGame の `banzhafValue` のヘルプが引用) | Banzhaf 値 (1.25, 0.75, 1.25) | 引用元の記載、手計算 |
| 手袋ゲーム (左 1 人・右 2 人、左 1 人・右 9 人、左 3 人・右 1 人) | CoopGame のテスト 15.2-15.6 (15.4-15.6 は Wiese の教科書 p. 65 を引用) | (2/3, 1/6, 1/6)、(9/10, 1/90, ...)、(1/12, 1/12, 3/4, 1/12) | 引用元の記載、手計算 |
| 重み (50, 49, 1) の投票ゲーム、基準 1, 51, 52, 100 | CoopGame のテスト 07.1 | 正規化 Banzhaf 指数 (1/3, 1/3, 1/3)、(3/5, 1/5, 1/5)、(1/2, 1/2, 0)、(1/3, 1/3, 1/3) | 引用元の記載、手計算 |
| 101 人の多数決ゲーム (サンプリング) | 対称性と二項分布 | Shapley 値 1/101、Banzhaf 値 C(100, 50) / 2^100 | 推定値が標準誤差の 5 倍以内 |

手計算の要点は次のとおり。

- Ibn Ezra: v(S) は S の最大の請求 (120 で頭打ち) で、LO1973 の形のゲームになる。
  請求を小さい順 (30, 40, 60, 120) に並べ、増分を必要とする人数で等分すると、
  30/4 = 7.5、7.5 + 10/3 = 10 5/6、10 5/6 + 20/2 = 20 5/6、20 5/6 + 60 = 80 5/6。
- Gambarelli: プレイヤー 1 の限界貢献は {}: 0、{2}: 1、{3}: 2、{2,3}: 2 で、和 5 を 2^2 = 4 で割って 1.25。
  プレイヤー 2 は 0 + 1 + 1 + 1 = 3 で 0.75、プレイヤー 3 は 0 + 2 + 1 + 2 = 5 で 1.25。
- 手袋ゲーム: 少数側の 1 人は、自分より前に多数側の人が 1 人でもいれば貢献 1 を得る。
  多数側が k 人ならその確率は k / (k + 1) で、残りを多数側の k 人で等分する。
- 重み (50, 49, 1)、基準 51: 勝利提携 {1,2}, {1,3}, {1,2,3} で、1 は 3 つとも決定的、2 と 3 は 1 つずつ。

また、BNF タイプ 1, 2, 4 の 12 ゲーム (n = 4-10) で、Shapley 値・Banzhaf 値を CoopGame 0.2.2 と比べ、
24 件全てが相対 2.3e-15 以内で一致した (`scripts/compare/check_values.py`)。

## カーネル

文献でカーネル全体の答えが示された例は、この環境で確認できる資料に見つからなかった。
代わりに、上の例の答えの点が `kernel_set` で求めたカーネル (プレカーネル) に含まれることを確かめた
(`literature_examples_lie_in_kernel_set`)。仁はカーネルに属する (MPS1979) ので、これは必要条件の確認である。
